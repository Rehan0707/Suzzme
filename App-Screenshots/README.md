## Capture coverage

This collection contains the labeled iOS and macOS captures listed above. Earlier design/runtime screenshots remain under `Suzzme/Design`. It does not imply every possible state or light/dark variation has been captured. iOS images come from the native iPhone 18 Pro simulator; Mac images come from native app windows. Physical iPhone Dynamic Island, Live Activity and haptic/voice hardware acceptance remain uncaptured. The current Mac onboarding was not reset to obtain screenshots. Native menu inspection succeeded, but the capture API did not return an image for the open menu, so no menu screenshot is fabricated.

Input Monitoring remains unchanged. Account connections and permission toggles were not altered. The Mac was returned to Home after capture. Screenshots may display the app's existing local content; this folder has not been uploaded or published.
