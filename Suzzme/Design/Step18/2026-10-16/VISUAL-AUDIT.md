# Step 18 visual audit — 16 October 2026

Inspected every referenced image: **33 native Mac screenshots and 48 presence preview renders; 0 missing gallery files**. Images were read directly after the browser blocked the local-file protocol. Contact sheets in `audit-contact-sheets/` index every source image. No screenshot observation below is inferred from compilation.

## Five priorities

1. Integration discovery: long preamble and unavailable catalog cards displace supported connection controls (P1).
2. Assistant reading space and action hierarchy: narrow Mac sheet and two bottom chrome bands, including icon-only Sources (P1).
3. Duplicate Speaking pace labels in Voice (P2).
4. Full-window decorative onboarding gradient (P2).
5. Missing target/answer text in presence **preview evidence**, requiring live-panel investigation before a production fix (P1 evidence gap).

**iOS white-screen acceptance is a separate P1 blocker:** no supplied iOS runtime image establishes either the failure or its resolution.

## Direction

Minimal Foundation + Signature Intelligence + Adaptive Workspace. Preserve the original three-stroke Face and Suzzme Purple. Neutral system surfaces carry navigation and forms; purple identifies important assistant interactions. Preserve native controls, readable width, keyboard routes and 44-point assistant targets. Keep idle calm and bind all live activity to the existing environment.
