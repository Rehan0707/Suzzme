# Knowledge source collection

Sentient OS is a reference implementation, not a runtime dependency. Its local-source guide and `WhatsAppSource.swift` show an explicitly selected set of chats read from WhatsApp for Mac's local `ChatStorage.sqlite`: it makes a short-lived WAL-safe copy, reads bounded conversation windows, then deletes the copy. This path needs macOS Full Disk Access. `AppleMailSource.swift` reads selected accounts from Apple Mail's local index and downloaded bodies; `AppleCalendarSource.swift` uses EventKit. Its hosted Gmail and Google Calendar path instead uses the user's ChatGPT or Claude connectors and is analyzed through those hosted engines, not an on-device model. Those are different privacy and availability tradeoffs.

Suzzme's existing path is `InformationSource` → `InformationEngine` → the on-device `InformationStore` → `ProactiveIntelligenceEngine` → Daily Summary. The engine refreshes enabled sources, checks authorization again when retrieving, deduplicates, and applies retention. Calendar, Reminders, Gmail, selected messages, selected Google resources, connected-app resources, and selected local WhatsApp chats feed this path. The prepared summary and its evidence stay on-device; Supabase stores only account identity. Gmail starts with `gmail.metadata` for sender and subject headers. A separate incremental `gmail.readonly` grant and source selection enables bounded message-body reads and on-device summaries. iMessage is not connected to its live database in Suzzme.

On macOS, the WhatsApp source asks the user to select WhatsApp's shared folder and then up to 20 chats. A security-scoped bookmark preserves that folder grant. Each enabled refresh makes a private temporary SQLite/WAL copy, queries only the selected chat IDs and recent text messages, deletes the copy, summarizes bounded conversation windows with Apple Intelligence, and stores only short summaries. A committed per-chat row watermark avoids repeating unchanged windows. Deselecting or disconnecting removes local WhatsApp summaries and prevents them from appearing in cached briefings. macOS may also require the user to grant Full Disk Access in System Settings; Suzzme cannot grant it itself. This source is Mac-only and requires an installed, locally synced WhatsApp database and an available on-device model.

The new review-first path for conversation exports is: select a plain-text export or paste text → on-device Apple Intelligence creates bounded short summaries in memory → user reviews the result → the existing message importer stores only the approved short text locally → the next Daily Summary can include it. If the on-device model is unavailable, no raw conversation is silently stored. The import does not claim account connection, automatic refresh, complete coverage, or a source message date. It provides a way to include real WhatsApp chat content now without taking Full Disk Access or using an undocumented WhatsApp API.

The Gmail-body path requests `gmail.readonly` separately from metadata access. It reads at most 12 recent message bodies per refresh, extracts bounded plain text (or sanitized HTML text), never fetches attachments, uses the on-device model, and stores only short summaries; other selected messages can contribute headers. If the on-device model is unavailable, it reads headers only. Turning summaries off retires their selection generation and removes old local records. Gmail API is enabled in the Suzzme Google Cloud project. Google classifies both Gmail scopes as restricted. The Google Auth Platform Data access configuration now saves both scopes with a truthful productivity use case and justification. The Verification centre reports that data access is unverified and that branding must be verified and published before requesting scope verification. A real demo video and restricted-scope review remain. A live Google-account acceptance run is also required; synthetic API fixtures and local builds cannot prove the OAuth consent screen accepts this app's configuration. The WhatsApp reader has a synthetic SQLite fixture check, but its security-scoped folder and Full Disk Access flow still need acceptance on a Mac with WhatsApp installed.
